## 浏览器回归（fixture.html）

1. `chrome://extensions` 刷新扩展 → 打开 `test/fixture.html`（本地文件需开启「允许访问文件网址」，或 `npx -y serve .` 后访问）
2. 点击扩展图标 → 面板应为**空态**「尚未收集任何列表」（无自动识别）
3. 对照 fixture.html 各区块注释的预期值逐项验证：

| 验证点 | 预期 |
| --- | --- |
| 空态 | 打开面板无任何列表，hint 引导「点击添加选择」 |
| 整表收集（div 卡片） | 「添加选择」→ 行出现「收集中」徽标 → 点击任一商品卡片（点卡片内标题/正文/链接均生效）→ 6 张卡片整表收集：悬浮时 6 张全部紫色高亮（范围预览），页面卡片显示序号框 1..6，面板行「6 条」；再次点击任一卡片 → 整表移除 |
| 整表收集（a 包裹网格） | SPA 段点击任一卡片 → 3 个同签名 `<a>` 兄弟整表收集为 3 条；导出默认单列「内容」 |
| li 整表收集 | 收集模式下点击评论 li 内任意位置（含链接文字）→ 整个 ul 的 10 个 li 整表收集为 10 行；再次点击任一 li → 整表移除 |
| 双列条纹整表（真列表语义 + 列优先排序） | 收集模式点击「双列条纹列表」任一 li → 全部 10 个 li 整表收集（odd/even 条纹类不拆列表），面板行「10 条」、页面徽标 1..10；导出行序 = 左列 1-5 自上而下再右列 6-10（DOM 交错序被列优先还原）；再次点击任一 li → 整表移除 |
| Ctrl 收子集 | 收集模式 Ctrl+点击左列任一 li → 只收左列 5 条（odd 严格签名）；Ctrl+点击右列 → 只收右列 5 条；再 Ctrl+点击左列 → 只移除左列条目（同容器按条目重叠 toggle）；Ctrl 按住悬浮 → 高亮预览同样式子集范围 |
| Ctrl 并组同 Sheet | 选择模式选中一个条目后 Ctrl+点击另一条目 → 两行徽标同号、标题「已选 2 · 1 Sheet」；导出 = 一个 Sheet 按选择序拼接（xlsx 单 Sheet / csv 单文件）；取消选中后并组解除 |
| 同签名 p 组 | 点击「行内吸附验证」任一段（含其内行内 span）→ 5 个 p 整表收集；导出内容 = 各段归一化文本（`4722 PHP 币种已合并` 等） |
| 单条收集（独立元素） | 无同签名兄弟的独立元素（「链接拦截验证」的 p）→ 单条收集进活动列表；再次点击移除；移除至 0 条 → 列表取消选中 |
| 拦截跳转 | 收集模式中点击「链接拦截验证」链接不跳转（收集其所在 p）；中键点击不新开标签；焦点在页面输入框按 Enter 不提交跳转；拖拽面板松开在页面上不误收集；Esc 结束后页面交互恢复 |
| SPA 路由拦截 | 收集模式点击「SPA 路由拦截」任一卡片 → 状态保持「未跳转」且整表收集 3 条（采集盾接管命中，window 捕获路由器无从触发）；悬浮任一卡片 → 3 卡同时紫色高亮；收集模式中滚轮滚动页面正常；常规模式点击任一卡片 → 状态变「已发生 SPA 跳转」（已知边界：路由器先于扩展执行，红框 + 警示 toast 仍出现） |
| 整表 toggle | 已收集商品列表后（同一次或新一次收集模式）点击其任一卡片 → 整表移除（非单条） |
| 跨列表防护 | 条目与其他收集列表重叠的结构 → toast「所选列表的元素已在其他收集中」不动作；独立元素已在其他列表 → toast「该元素已在其他收集中」 |
| 结束收集 | Esc / 「完成收集」→ 徽标消失，行保留且选中；未收集任何元素时 Esc → 活动列表整行移除回到空态 |
| 悬浮联动 | 悬浮面板条目 → 页面该列表全部元素紫色高亮框；悬浮页面已收集元素 → 面板条目滚入并短暂强调 |
| 选中切换 | 常规模式点击已收集元素 → 取消/恢复该列表选中（覆盖层消失/恢复）；贴屏幕边缘徽标翻内侧 |
| 字段 · 链接列 | 收集评论列表 → 字段视图「＋ 点选」点评论内链接 → 字段类型 = link → 导出多一列链接（li 内 a 的绝对地址） |
| 字段 · 自动识别 | 收集「字段提取验证」5 条评论 → 面板行「字段」→「自动识别」→ 识别出 6 个字段（作者/日期/标题/内容/链接/点赞），预览表 5 行命中；改名/删字段/调类型即时反映在预览 |
| 字段 · 手动点选 | 「＋ 点选」→ 点击任一评论内的作者名 → 新增字段并推广到全部 5 条（预览每行都有值）；点击 a 链接 → 类型自动为 link，值 = 绝对地址；点击条目外元素不高亮不收集 |
| 字段 · 命中率 | 删除「日期」字段前先改其选择器为无效值（或在结构不同的列表上识别）→ 字段行命中率显示不足，导出该列空串不丢行 |
| 字段 · 清空 | 字段视图「清空」→ 回到单列「内容」导出（与旧行为一致） |
| 字段 · 无字段默认 | 未定义字段的列表导出 = 单列「内容」，各格式表头与 v1.3 一致 |
| 字段 · 深层嵌套 + 稳定锚点 | 收集「深层嵌套评论」3 条 →「自动识别」→ 名称/图标/标题/日期/有用数/正文经 data-hook 生成 `[data-hook="xxx"]` 选择器（跨条目结构差异仍命中）；隐藏 teaser 文本不产生候选；「正文」= 多段正文合并为单一字段（第一条两段都在，无单独「首段」字段） |
| 多列表导出 | 两个收集列表多选：xlsx 多 Sheet（收集1/收集2）；csv 拆多文件（带列表名后缀）；json 键嵌套；md 二级标题分区；html 多表串接 |
| 文件名钳制 | 文件名输入框粘贴 100+ 字符长名 → 导出后实际文件名 ≤100+扩展名（多列表 csv 带后缀时主体 ≤60）；长标题页面（可临时改 fixture 的 `<title>`）默认名标题部分 ≤40 字符 |
| 链接拦截 | 常规模式点「链接拦截验证」的链接 → 拦截 + 红框 + 警示 toast；收集模式点击 → 收集元素不跳转 |
| 交互放行 | 常规模式点击非收集区域（滚动、普通文本）不拦截 |
| 失联剔除 | 收集后触发页面替换 DOM（如翻页）→ toast「已收集元素被页面刷新移除」，空列表整行移除 |
| 图标再点 | 面板打开时点图标 → 面板收起（收集列表保留）；再点图标 / Esc /「退出」→ 全部清理 |
| 深色模式 | 系统切深色 → 面板/toast 跟随 |

## 已知不覆盖

- pickItem 吸附与 findContainingList 列表识别（依赖 getComputedStyle / DOM 结构）与 UI 交互无自动化，依赖上表人工回归
- xlsx 二进制结构（Sheet 名 / 列宽钳制）以打开文件目测为准
