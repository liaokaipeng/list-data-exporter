# 产品文档

## 定位

扩展名称：**List Data Exporter：导出列表**（图标与文案风格对齐 web-table-exporter：品牌紫底 + 白色列表符号）。

面向运营/数据用户：把网页上**想留下的内容**（评论、商品、公告、搜索结果条目等）逐个点击收集，导出为 Excel / CSV / JSON / Markdown / HTML，无需手动复制粘贴。与 web-table-exporter 互补：前者管 `<table>` 整表抓取，本扩展管散落页面元素的**手动逐条收集**。

核心策略：**手动收集为唯一通道**——不做自动识别、不做站点适配器；用户逐个点击元素，每次点击 = 列表中的一条数据，多次点击累积为一个收集列表。

## 核心用户故事

1. 我打开一个页面，想把几条商品信息变成 Excel → 点击扩展图标 →「添加选择」进入收集模式 → 逐个点击想要的元素，页面即时出现序号标记（1、2、3…），面板计数同步增长
2. 点错了 → 收集模式中再次点击已收集元素即移除，序号自动重排
3. 我想要两个独立列表（比如商品一批、评论一批）→ 第一次收集完 Esc 结束，再次「添加选择」新建一个收集列表；两个列表多选一次性导出（xlsx 每列表一个 Sheet）
4. 想要文本也想要链接 → 面板可勾选「附链接列」：每行追加元素内第一个 `<a>` 的绝对地址
5. 不确定面板里哪条对应页面哪块 → 悬浮面板条目，页面上该列表**全部已收集元素**紫色高亮；悬浮页面已收集元素，面板条目滚入视野并短暂强调（双向联动）
6. 我想自己命名文件 → 面板可改文件名
7. 导出一次后想换格式再导一次 → 导出成功后保留面板不自动退出，toast 提供「退出」动作

## 收集规则（点击吸附）

点击处向上吸附为「视觉上独立的一条」，规则由内向外：

| 规则 | 说明 |
| --- | --- |
| li 优先 | 点击列表条目内任意位置（含标题、链接文字）→ 吸附到整个 `li` |
| 行内 → 块级 | 点击行内元素（`display:inline`，如 span/a/b）→ 向上吸附到最近的块级容器 |
| 块级即停 | 点击块级元素（div/p/h3/卡片等）→ 取该元素自身 |
| 边界保护 | `body` / `documentElement` 不作为候选 |
| 内容口径 | 元素 `textContent` 归一化（换行/连续空格合并为单个空格）；「附链接」= 元素自身或内部第一个 `<a>` 的绝对地址 |

## 交互规范

### 入口与退出

| 操作 | 行为 |
| --- | --- |
| 点击扩展图标 | 打开收集面板（已打开则收起面板不退出会话，再点退出） |
| 再次点击图标 / Esc / 面板「退出」 | 退出，清理全部 UI 与监听 |
| Enter | 导出（焦点在面板输入框/按钮上时走默认行为，页面元素持焦时放行给页面） |

### 收集面板（可拖拽悬浮窗）

- **形态**：右侧默认贴边的悬浮窗（宽约 360px，上限 95vw / 视口高的 70% 内自滚），标题栏可拖拽移动到任意位置，位置本次会话内记忆；深色模式跟随系统；支持减弱动效（prefers-reduced-motion）

- **标题栏**：扩展名 + 已选计数 + 「退出」

- **条目结构**（每个收集列表一行）：
  - 序号徽标（选中后与导出顺序一致）
  - 首条内容预览：第一条数据的文本，截断约 40 字符，悬浮显全文
  - 条目数（如「12 条」）
  - 「收集中」徽标（仅收集模式中的活动列表显示）
  - 「附链接」勾选（默认不勾选，见用户故事 4）

- **悬浮联动**：鼠标悬浮面板条目 → 页面上该列表**全部已收集元素**逐一加紫色高亮框（同 web-table-exporter 高亮框样式，跟随滚动定位）；收集模式中悬浮页面元素时同风格高亮吸附候选

- **选中**：点击面板条目 → 选中（条目行高亮 + 页面该列表每个元素加半透明紫色覆盖层 + 列表内序号徽标，贴屏幕边缘时徽标自动翻内侧）；再点取消。悬浮页面中任意已收集元素，面板对应条目滚入视野并短暂强调

- **收集模式**（核心通道）：面板底部「添加选择」→ 进入收集模式（按钮变「完成收集」，新建一个收集列表，每次进入新建）：悬浮高亮吸附候选，点击收集为一条；再次点击已收集元素移除（序号重排）；点击属于其他列表的元素 → toast 提示不动作；收集第一条时列表自动进入选中态。Esc / 「完成收集」结束，未收集任何元素则该列表移除

- **操作区**（面板底部）：文件名输入框（默认 `页面标题_yyyyMMdd-HHmmss`，非法字符替换为 `_`）、导出格式下拉（Excel / CSV / JSON / Markdown / HTML，默认 Excel，切换时导出按钮文案同步）、「导出」按钮（未选非空列表时禁用，导出中变「导出中…」防误点）、「取消」

- 非收集模式下页面交互可用：非收集元素点击放行给页面（翻页、筛选照常）；仅拦截已收集元素点选与链接导航（被拦链接红框高亮 1 秒 + 警示 toast）；被页面交互替换的已收集元素自动剔除（空列表整行移除并提示）

### 导出结果（全格式公共）

- **数据模型**：收集列表 → 一列「内容」，每个已收集元素一行；文本按视觉归一化（换行/连续空格合并为单个空格，如 `4722 PHP`）；勾选「附链接」的列表追加「链接」列（元素自身或内部第一个 `<a>` 的绝对地址，无则留空）

- **文件名**：按所选格式自动补 `.xlsx` / `.csv` / `.json` / `.md` / `.html`；多列表 csv 拆多个文件（文件名带列表名后缀，单列表不带）

- **xlsx**：多列表 → 多 Sheet，Sheet 名：收集N（N 按导出序）；单元格按文本写入（长数字/前导零不丢）；列宽自适应（中文按双宽估算，钳制 6~50 字符）

- **csv**：RFC 4180 转义、UTF-8 BOM + CRLF，Excel 直开不乱码

- **json**：单列表 = 行对象数组；多列表 = 列表名键嵌套

- **md**：GitHub 风格表格，多列表二级标题分区，单元格内换行转 `<br>`

- **html**：完整 HTML 文档（UTF-8 声明 + 极简样式），多列表串接

- **下载**：经扩展后台 API（chrome.downloads，不受页面 CSP 限制），失败自动回退页面内下载

## 状态反馈（双通道）

面板 hint 行只承载引导与进行时文案；结果性通知走右上角 toast（成功/信息 2.5 秒自动消失，错误常驻 + 关闭按钮，同屏最多 3 条）。

| 通道 | 状态 | 文案 |
| --- | --- | --- |
| hint | 默认（无收集） | 点击「添加选择」，逐个点击页面元素收集数据 |
| hint | 默认（有收集） | 悬浮条目查看已收集元素，点击选择（可多选） |
| hint | 收集模式（初始） | 点击要收集的元素，再次点击移除（Esc 结束） |
| hint | 收集模式（进行中） | 已收集 N 条，继续点击或 Esc 结束 |
| hint | 导出中 | 正在生成导出文件… |
| toast | 导出成功 | 已开始下载… / 已下载 N 个文件（含「退出」动作；保留面板可连续导出） |
| toast | 生成失败 | 导出失败：<原因>（常驻可关） |
| toast | 跨列表点击 | 该元素已在其他收集中 |
| toast | 元素失联 | 已收集元素被页面刷新移除（N 条，含空列表） |
| toast | 链接点击被拦截 | 选择模式下链接已停用，Esc 退出后可跳转（警示样式停留 4 秒） |

## 已知限制（用户须知）

- 吸附粒度由固定规则决定（li 优先 / 行内→块级），无法自定义边界；点到的块级元素整体成一条（含其全部子文本）
- 仅导出收集时已加载的元素：分页/懒加载内容需先翻页/滚动加载后继续收集（自动翻页采集是后续版本方向）
- 一个元素同一时间只能属于一个收集列表（跨列表点击会提示）；如需复用，重新收集即可
- 条目内容导出文本与链接，不含图片本身和样式
- 收集列表与会话绑定，关闭面板（退出）即清空，不跨会话保存（持久化是后续版本方向）
- 不支持 iframe 内的元素收集（后续版本方向）
